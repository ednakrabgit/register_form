6. ระบบสำรองข้อมูลและ Deploy ขึ้นคลาวด์ (Database Backup & Cloud Deploy):
--------------------------------------------------------------------------------
   * สคริปต์หลัก:
     C:\Users\ednak\OneDrive\Desktop\datamangement\www\db\backup_sqlserver_db.bat

   * ขั้นตอนที่สคริปต์ทำงานอัตโนมัติแบบครบวงจร (One-Click Automated Pipeline):
     1) ตรวจสอบความพร้อมของ Docker Engine และคอนเทนเนอร์ mssql2025 (หากปิดอยู่จะ Start ให้อัตโนมัติ)
     2) สั่งคำสั่ง BACKUP DATABASE [thaiairp_iptc] WITH COMPRESSION ใน SQL Server
     3) ดึงไฟล์ .bak ออกมาเก็บไว้ที่เครื่อง Local:
        C:\Users\ednak\OneDrive\Desktop\datamangement\www\db\thaiairp_iptc_backup_YYYYMMDD_HHMMSS.bak
     4) อัปโหลดไฟล์ .bak ขึ้น Google Cloud Storage Bucket:
        - gs://viriyahiptc2/db_backup/thaiairp_iptc_backup_YYYYMMDD_HHMMSS.bak
        - gs://viriyahiptc2/db_backup/latest.bak (สำเนาเวอร์ชันล่าสุด)
     5) ซิงค์ข้อมูลจาก SQL Server 46 ตาราง เข้าสู่ SQLite app.db ผ่าน export_mssql_to_sqlite.py
     6) สั่ง Deploy คอนเทนเนอร์ register-backend เวอร์ชันใหม่ขึ้นสู่ Google Cloud Run อัตโนมัติ
